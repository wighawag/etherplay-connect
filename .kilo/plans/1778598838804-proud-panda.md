# Plan: Fix ConnectionStore Interface & Generic generateOriginAccount

## Problem
Two remaining issues after the authentication handler refactoring:

1. **`ConnectionStore` interface missing `subscribe`** — The implementation returns `subscribe: stateStore.subscribe` at handler.ts:83, but the `ConnectionStore` interface (handler.ts:13-17) doesn't declare it. This means TypeScript doesn't know `ConnectionStore` is a Svelte store.

2. **`generateOriginAccount` uses non-generic type access** — At handler.ts:89, the code accesses `provider['openfortInstance']?.embeddedWallet?.signMessage(...)` using bracket notation with a magic string. This breaks the generic provider abstraction and won't work for other providers.

## Solution

### Step 1: Add `subscribe` to `ConnectionStore` interface

In `web/login/src/lib/handler.ts`, add `subscribe` to the `ConnectionStore` interface:

```typescript
import type { Writable } from 'svelte/store';

export interface ConnectionStore extends AuthProvider, Writable<AuthState> {
    generateOriginAccount: (origin: string, account: AuthResult) => Promise<OriginAccount>;
    provideEmail: (email: string) => Promise<void>;
    provideMnemonicIndex: (index: number) => Promise<void>;
}
```

This makes `ConnectionStore` a proper Svelte writable store, enabling `$connection` syntax in components.

### Step 2: Define `AccountGenerator` interface for text signing

The `AccountGenerator` interface from `@etherplay/wallet-connector` already has `signTextMessage`, but `generateOriginAccount` needs access to it. The current factory already receives `accountGenerator` as a parameter — we just need to use it.

The Alchemy reference implementation (`packages/etherplay-alchemy/src/index.ts:596-630`) shows the correct pattern:
```typescript
const originKeySignature = await settings.accountGenerator.signTextMessage(
    originKeyMessage(origin),
    accountObject.privateKey,
);
```

### Step 3: Refactor `generateOriginAccount` in `createOpenfortConnection`

Replace the non-generic Openfort-specific code with the generic `AccountGenerator` pattern:

**Current (handler.ts:84-113):**
```typescript
generateOriginAccount: async (origin: string, account: AuthResult) => {
    if (!currentAccount) {
        throw new Error('No account available');
    }
    const originKeyMsg = originKeyMessage(origin);
    const signature = await provider['openfortInstance']?.embeddedWallet?.signMessage(originKeyMsg);

    if (!signature) {
        throw new Error('Failed to sign origin key message');
    }

    const originKey = fromSignatureToKey(signature as `0x${string}`);
    const originMnemonic = fromEntropyKeyToMnemonic(originKey);
    const originAccount = accountGenerator.fromMnemonicToAccount(originMnemonic, 0);

    return {
        address: account.address,
        signer: {
            origin,
            address: originAccount.address,
            publicKey: originAccount.publicKey,
            privateKey: originAccount.privateKey,
            mnemonicKey: originKey,
        },
        metadata: account.metadata,
        mechanismUsed: account.mechanismUsed,
        savedPublicKeyPublicationSignature: account.savedPublicKeyPublicationSignature,
        accountType: account.accountType,
    };
},
```

**New (using AccountGenerator):**
```typescript
generateOriginAccount: async (origin: string, account: AuthResult): Promise<OriginAccount> => {
    if (!currentAccount) {
        throw new Error('No account available');
    }

    const accountMnemonic = fromEntropyKeyToMnemonic(currentAccount.signer.mnemonicKey);
    const accountObject = accountGenerator.fromMnemonicToAccount(accountMnemonic, 0);

    const originKeySignature = await accountGenerator.signTextMessage(
        originKeyMessage(origin),
        accountObject.privateKey,
    );

    const originKey = fromSignatureToKey(originKeySignature);
    const originMnemonic = fromEntropyKeyToMnemonic(originKey);
    const originAccount = accountGenerator.fromMnemonicToAccount(originMnemonic, 0);

    return {
        address: account.address,
        signer: {
            origin,
            address: originAccount.address,
            publicKey: originAccount.publicKey,
            privateKey: originAccount.privateKey,
            mnemonicKey: originKey,
        },
        metadata: account.metadata,
        mechanismUsed: account.mechanismUsed,
        savedPublicKeyPublicationSignature: account.savedPublicKeyPublicationSignature,
        accountType: account.accountType,
    };
},
```

Key changes:
- Derive `accountObject.privateKey` from `currentAccount.signer.mnemonicKey` via `accountGenerator.fromMnemonicToAccount()` instead of accessing Openfort internals
- Use `accountGenerator.signTextMessage()` instead of `provider['openfortInstance']?.embeddedWallet?.signMessage()`
- Import `OriginAccount` type from `@etherplay/connect-core`
